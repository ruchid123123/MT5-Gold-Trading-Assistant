# MT5 黄金交易助手

一个专为黄金（XAU/USD）交易设计的 MetaTrader 5 辅助工具，提供风险计算、仓位管理和自动追踪止盈功能。

## 功能特点

### 黄金专用风险计算器
- 自动获取黄金实时价格（支持 XAUUSD、GOLD、XAUUSDm 等代码）
- 基于账户余额和风险比例自动计算建议仓位
- 显示止损距离（pips）、实际风险金额
- 支持止盈计算，显示盈亏比

### 订单管理
- 实时显示持仓列表
- 部分平仓功能（10%、25%、50%、75%、100%）
- 移动止盈（TTP）：触及 TP 后自动移动止损
- 自动读取 MT5 账户余额

### 其他功能
- 深色/浅色主题切换
- 日志窗口
- 实时价格更新

## 安装要求

### 系统依赖
- Python 3.8+
- MetaTrader 5 终端软件（需登录）

### Python 库
```bash
pip install PyQt5 MetaTrader5
```

## 使用方法

### 1. 启动程序
```bash
python mt5_assistant_cn.py
```

### 2. 连接 MT5
点击"连接 MT5"按钮，程序会自动连接本地运行的 MetaTrader 5。

### 3. 使用计算器
1. 切换到"风险计算器"页面
2. 点击"获取黄金现价"自动填入当前价格
3. 输入止损和止盈价格
4. 点击"计算建议仓位"

### 4. 订单管理
- "部分平仓"：选择比例后确认平仓
- "TTP"：设置三个止盈目标和缓冲点数，触及后自动移动止损

## 计算说明

### 黄金计算参数
- 1标准手 = 100盎司
- 1 pip = 0.01美元
- 点值 = $1/每pip/每标准手

### 仓位计算公式
```
风险金额 = 账户余额 × 风险比例%
止损点数 = |进场价 - 止损价| / 0.01
建议手数 = 风险金额 / (止损点数 × 1)
```
